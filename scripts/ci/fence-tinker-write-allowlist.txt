# A marker not listed here exempts nothing. Pinned by

# closed on the drift.
#
# CONVENTION (Sec, PR #862 review, single-namespace ruling): both anchor
# classes share this ONE marker namespace -- there is no separate ID
# series for an indirect/unresolvable-body site. Because of that, an
# entry for a marker bound to an unresolvable `--execute=` invocation
# (mode ii -- see fence-tinker-write-allowlist.sh's own header) MUST
# lead its purpose text with the tag `[INDIRECT-BODY]` and state which
# literal write-verb line, if any, it stands in for and how far away it
# is. This is the only place that distinction is carried once the
# namespace is shared -- a reviewer must be able to tell "we reviewed
# this specific write" from "we accepted a body we could not read" from
# this file's text alone.
