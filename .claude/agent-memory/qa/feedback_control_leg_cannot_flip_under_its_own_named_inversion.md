SELF-263 Sec A-1 (2026-09-04): Sec's inversion criterion read "(D3)/(D4)/(D5) must
go RED while BF5–BF8 stay GREEN" for striking migration 100's statement (3) (the
taxonomy_default 25-row UPDATE). D3/D4 went RED as specified. **D5 — "Real Estate
rows remain tax_relevant=false" — stayed GREEN, and cannot do otherwise under this
strike**: Real Estate was never in statement (3)'s corrected VALUES list in the
first place, so removing that statement changes nothing about the Real Estate
rows' state. D5 is the real-table re-aim of BF8, itself a documented CONTROL leg
in the original battery (proves "untouched", not "corrected") — and BF8 exhibits
the identical always-green behavior under the same strike.

Sec's own general clause elsewhere in the same review — *"If any proposed leg
cannot be made to red this way, it is not the leg"* — reads as if it should
disqualify D5. It does not: that clause is about legs claiming to WATCH a
correction; D5/BF8 are explicitly framed as controls proving a non-correction
held, a different class with a different (and here, un-exercised) inversion
target — e.g., corrupting the guard so it wrongly touches Real Estate, not
removing the statement entirely.

**Why:** loose assertions are not honest — reporting "D3/D4/D5 all went red as
Sec specified" would have been a false composite claim (two of three legs
matched literally, the third structurally cannot under this strike, and that's
correct, not a gap). [[feedback_verify_causal_mechanism_before_stating]] and
[[feedback_inversion_test_the_rationale_not_the_presence]] both apply: state
what actually moved, not what the brief predicted would move.

**How to apply:** when a dispatch brief bundles several legs under one inversion
and asserts they all flip, run each leg's actual result and report divergences
explicitly rather than rounding up to "confirmed as specified." A control leg
that stays green under the SPECIFIC inversion named is not a defect in the leg —
say so, and name what inversion WOULD exercise it if that matters to the reader.
