## Review method

- [Run the measurements a ruling needs](feedback_run_the_measurements_a_ruling_needs.md) — read-only measurement is REVIEW work, not the builder's; route back only builds/fixes and expensive reproductions.
- [Measure the fence regex, not its comment](feedback_measure_the_fence_regex_not_its_comment.md) — grep the real predicate over an evasion list; a two-stage fence leaks between the stages and NULL is the silent pass; a raise-classifier chain with a gap falls through to a 500.
- [Sec-Lock cross-check catches my own misreads](feedback_sec_lock_cross_check_catches_my_own_misreads.md) — read the source the text CITES; a relay of my OWN words is still a relay; my own ROLE BRIEF's Lock gloss can scope a surface OUT.
- [Catalog comments carry live-state tallies](feedback_catalog_comments_carry_live_state_tallies.md) — a count FANS OUT; AUTHORED ≠ SERVED (`DROP`+`CREATE` destroys the earlier `comment on`); a sweep claim is a claim about the grep's ENCODING (`docs/**` is HTML).
- [Zero-value sentinels flip meaning when a predicate changes](feedback_zero_value_sentinel_flips_meaning.md) — re-check EMPTY / `?? DEFAULT` / prop defaults; a `=== 0` guard is a NaN guard, not a domain guard; ⚠ `GREATEST`/`LEAST` IGNORE NULLs, so the guard itself mints the zero; a new UNKNOWN state whose identity element is the OLD behaviour makes landed equality legs VACUOUS, not red.
- [A ruling's text makes claims about the tree](feedback_a_ruling_makes_claims_about_the_tree.md) — at the pre-ruling grade the NAMED WATCHER, the PREMISE and the "open" question as claims; ⚠ a `comment on` can assert the CONSUMER's behaviour, be wrong, and have the shortest fix window in the repo.
- [A preference reads as a ruling; a caveat sets the axis](feedback_a_preference_reads_as_a_ruling_and_a_caveat_sets_the_axis.md) — measure the SIBLING's convention first; refuse a premise that presupposes a discriminator that doesn't exist; label every list FLOOR or SPEC.
- [Block when the vehicle cost inverts at merge](feedback_block_when_the_vehicle_cost_inverts.md) — return-shape rulings are free pre-merge; an assigned-but-never-read local is a dropped output column.
- [A stated invariant stronger than the contract](feedback_stated_invariant_stronger_than_the_contract.md) — retracting a claim, quote the WHOLE sentence: the tail may be a live obligation.
- [Read the whole cell before diagnosing doc drift](feedback_read_the_whole_cell_before_diagnosing_doc_drift.md) — supersession looks like drift on a partial read; ask what my correction would UN-cover.
- [Corrupt-the-control canary: how it fails to bite](feedback_corrupt_the_control_canary_boundary_tie.md) — corrupt the relation whose regression the fence NAMES; what works is a BOUNDARY PAIR one step apart; verify placement by what runs AFTER a `lives_ok`.
- [A RED whose message names the wrong defect](feedback_a_red_whose_message_names_the_wrong_defect.md) — the message dictates the repair, and the tempting repair disables the watcher; a TITLE can state the inverse of its own assertion; a `= 0` leg after a tenant switch passes vacuously forever.
- [Clearance conditions must absorb my own recommendations](feedback_clearance_conditions_must_absorb_my_own_recommendations.md) — "comment-only" goes stale the moment I ask for a code fix; probe the residual, don't hedge it.
- [My review measurements become quoted sources](feedback_my_review_measurements_become_quoted_sources.md) — re-run the command in the SAME turn as writing the number; ⚠ re-read the RULING that adopts a finding — the fix can re-commit the error class, and it invalidates battery legs' prose too.
- [Read the branch from the ref, not the worktree](feedback_read_the_branch_from_the_ref_not_the_worktree.md) — NO BARE PATH IN A REVIEW; `grep -n` on a pipe numbers the STREAM; ⚠ a grep over a DIFF answers "did it change", not "is it true" — a stale base reports a landed sentence as ABSENT; in-place edits need a non-comment perturbation count.
- [A prose-described fence is wrong TWICE](feedback_fence_shape_stated_in_prose_is_wrong_twice.md) — derive the refused set from the defect mechanism; prefer a STATE invariant on NEW over a `DISTINCT FROM` transition guard.
- [Triage a multi-leg bypass leg by leg](feedback_triage_a_multileg_bypass_leg_by_leg.md) — usually most legs are inert and ONE is live. ⚠ Grep the tree BEFORE ruling a finding novel — and before calling an absence an OMISSION, ask what the DISCHARGE would have looked like.
- [An unblocking fix un-masks every input class](feedback_an_unblocking_fix_unmasks_every_input_class.md) — a path that ALWAYS failed was fencing every class for free; enumerate the input dimensions and walk each.
- [A hazard has two falsifiable halves: MECHANISM · REACHABILITY](feedback_hazard_mechanism_vs_reachability.md) — I once accepted a fence against an unreachable threat, then embellished it. A shipped CAPABILITY is not a LIVE path.
- [Verify the cited SUBSECTION, not the headline](feedback_verify_the_cited_source_subsection_not_the_headline.md) — the falsifier lives in "the following shall not apply"; a plausible sibling number in the SAME document is the drift vector; a wrong INSTRUCTION costs more than a wrong constant.
- [A citation has four falsifiable axes: pointer · content · extent · attachment](feedback_read_decisions_from_the_pr_branch_when_the_pr_edits_it.md) — locate by bracketing `## ADR-` header, never line number; read AMENDMENTS; the FIX has the same axes. ⚠ A label sweep tests only POINTER — when an AC carries a quantifier ("all three states"), open the cited leg and COUNT; and an identifier you supply in commit-ready text is a claim it exists.
- [Supplied verbatim text ships unfiltered](feedback_supplied_verbatim_text_ships_unfiltered.md) — match the TARGET FILE's convention; my block's factual claims read as the receiving file's own; re-read my landed text at the re-confirm.
- [temp/ hand-off paths are per-worktree](feedback_temp_handoff_path_is_per_worktree.md) — give the absolute path; commit-ready text goes in the FILE *and* the message.
- [A carried file can be stale against its OWNING branch](feedback_carried_file_can_be_stale_against_its_owning_branch.md) — diff cross-ref, not just vs main. ⚠ Both directions: "this control exists" AND the reassuring "nothing moved" are CLAIMS; re-verdict per finding, append a dated clearance block.
- [Supplied text ending mid-sentence orphans the tail](feedback_supplied_text_ending_midsentence_orphans_the_tail.md) — name the splice boundary on BOTH sides; and ENDORSE a committer's scope expansion when my enumeration was short.
- [Review the delivery note against the ref](feedback_review_the_delivery_note_against_the_ref.md) — a `temp/` v2 over a v1 branch means the green run named another tree; a teammate's local suite figure ≠ the fenced CI lane.
- [Diff filter swallows removed comments](feedback_diff_filter_swallows_removed_comments.md) — a deleted `--` line reads as `---`; assert "zero executable lines changed", not "comment-only".
- [Auditing a consolidation against my own file](feedback_consolidation_drift_catch_method.md) — a quote attributed to me may be LAUNDERED from a teammate's file; a re-aimed axis deletes the gap; enumerate my ids first or omissions stay invisible.

- [An enumeration and its watcher both stop one short](feedback_enumeration_and_watcher_stop_one_short.md) — incl. the ASYMMETRIC-LEG variant (a late corrective term lands on one leg of a parallel pair); `polwithcheck` watched but never `polqual`; never demote a control to make its prose true. ⚠ UPSTREAM: grep drafted ACs for bare instance NUMBERS — reusing a RETIRED label reads as canon, not as a mistake; and check a proposed fence has two facts that can disagree.
