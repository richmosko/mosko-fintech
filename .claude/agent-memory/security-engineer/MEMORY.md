# Memory index — security-engineer

## Review method

- [Measure the fence regex, not its comment](feedback_measure_the_fence_regex_not_its_comment.md) — grep the real predicate over an evasion list; empirical probe when the matcher is someone else's engine; prescribe a positive pin over a name-denylist; **a two-stage fence leaks between the stages and NULL is the silent pass**; **inverse: a raise-classifier CHAIN with a gap falls through to a 500 — enumerate every trigger on the WRITTEN table, and ask what an unfiltered picker lets a user choose**.
- [Sec-Lock cross-check catches my own misreads](feedback_sec_lock_cross_check_catches_my_own_misreads.md) — read the source the text CITES; a relay of my OWN words is still a relay; "not in the tree" ≠ unrecoverable (Linear/DESIGN); quote an interior span; **my own ROLE BRIEF's Lock gloss can be narrower than canon and scope a surface OUT**.
- [Catalog comments carry live-state tallies](feedback_catalog_comments_carry_live_state_tallies.md) — a count FANS OUT (TOC + hint + body); negative-grep the old string, derive the number from a sibling catalog's convention, never sweep scoped historical deltas. **So does a CLASSIFICATION claim — grep past the brief's file list and follow inbound cross-refs.**
- [Zero-value sentinels flip meaning when a predicate changes](feedback_zero_value_sentinel_flips_meaning.md) — re-check EMPTY/`?? DEFAULT` **and prop defaults**; branch on the full state tuple, not one field; **a `=== 0` division guard is a NaN guard, not a domain guard — ask about the SIGN**; a "MIRROR of X" lib can drop X's gate (diff the SIGNATURES); the degenerate-state fixture gets shaped to the claim; **a fold's EMPTY-input path returns the identity element and never reaches the helper's short-circuit**; **positive operands ≠ positive quotient — `round(a/b,4)` can hit 0.0000, and an EXISTENCE watcher can't see it**.
- [A preference reads as a ruling; a caveat sets the axis](feedback_a_preference_reads_as_a_ruling_and_a_caveat_sets_the_axis.md) — measure the SIBLING field's convention before preferring; a true fact on the wrong axis becomes an inherited frame; **a "supply the rationale" request can presuppose a discriminator that doesn't exist — refuse the premise, don't fill the template**; **label every list I hand over FLOOR or SPEC, and check its BEHAVIOUR column is non-empty — a posture-only list watches the catalog, not the fence**.
- [Block when the vehicle cost inverts at merge](feedback_block_when_the_vehicle_cost_inverts.md) — return-shape rulings are free pre-merge; an assigned-but-never-read local is a dropped output column.
- [A stated invariant stronger than the contract](feedback_stated_invariant_stronger_than_the_contract.md) — "NULL together"/"exactly where" over a one-way rule; retracting a claim, quote the WHOLE sentence (the tail may be a live obligation); a forward note seeds the label it predicts.
- [Read the whole cell before diagnosing doc drift](feedback_read_the_whole_cell_before_diagnosing_doc_drift.md) — supersession looks like drift on a partial read; ask what my correction would UN-cover.
- [Corrupt-the-control canary: how it fails to bite](feedback_corrupt_the_control_canary_boundary_tie.md) — ties/loses to third-party rows; wrong probe; framing-not-mechanism fix; two-sided leg; count-not-winner companion; **corrupt the relation whose regression the fence names, not a sibling**; **a helper can LEAK the RLS role so the NEXT leg is vacuous — read what runs BEFORE a `0`-expecting leg, and grep which fixture verbs restore**. **What WORKS: a BOUNDARY PAIR one step apart, all else identical; a `lives_ok` control persists rows — verify placement by what runs AFTER it.** ⚠ **A `lives_ok` writing the row's ALREADY-SEEDED value cannot fail — diff any retargeted assertion's destination against the seed; a new fence can collapse the legal value-space to one member.** ⚠ **Fewer inversion failures than predicted = surgical probe, not loose one — count the guard's raise sites and their own gating predicates before doubting it; a singular noun ("the check") often names two things.**
- [A RED whose message names the wrong defect](feedback_a_red_whose_message_names_the_wrong_defect.md) — the message dictates the repair, and the tempting repair (`distinct`) disables the watcher; predict the post-change delta BEFORE it runs (bind it to the PROPERTY, not the instrument); a fix that BREAKS a venue reveals what the venue was standing on; fresh-stack CI is clean by construction, not by verification. **GREEN counterpart: a leg can name an observer it isn't exercising — recompute a stated window's endpoints and check which side the fixture is on. LAYER-MOVE: a new upstream guard SHADOWS the old layer's observer.**
- [Clearance conditions must absorb my own recommendations](feedback_clearance_conditions_must_absorb_my_own_recommendations.md) — "comment-only" goes stale the moment I ask for a code fix; VENUE clearances AND either/or remediations need a per-scope check (cluster vs database); ordering ≠ executability (`rolsuper` is an attribute, never inherited); probe the residual, don't hedge it; **an accept-with-compensating-controls disposition re-purposes my conditions without editing them — say they changed job, and that their tests are posture watchers**.
- [My review measurements become quoted sources](feedback_my_review_measurements_become_quoted_sources.md) — a ⭐ measurement gets copied byte-exact into a later migration header; my CORRECTION carried a new typed count; a digest is a pipeline property, assert `count(distinct)=1`; **and a quote I attributed to `fooBar.ts` actually lived in its case-twin mirror `foo-bar.ts` — grep BOTH, and run Sec-Lock on my OWN prose.**
- [Read the branch from the ref, not the worktree](feedback_read_the_branch_from_the_ref_not_the_worktree.md) — a parked worktree is merges behind; `ls` makes a valid citation look fabricated; **`grep -n` on a piped stream numbers the STREAM — quote the sentence, treat the number as advisory**; zsh eats `"$B:path"` (brace it); never `git checkout <ref> -- .` to read.
- [A prose-described fence is wrong TWICE](feedback_fence_shape_stated_in_prose_is_wrong_twice.md) — "refuse non-X" over an enum sweeps in siblings (derive the refused set from the defect mechanism); a `DISTINCT FROM` transition guard leaks the OTHER write order — prefer a STATE invariant on NEW (a WHEN on INSERT OR UPDATE can't reference OLD), and re-test a scoping objection after narrowing the predicate.
- [Triage a multi-leg bypass leg by leg](feedback_triage_a_multileg_bypass_leg_by_leg.md) — "N rules uncovered" usually means most are inert or already fenced and ONE is live; trace the survivor to a rendered control, and watch for a ruling enforced only on the READ side.
- [A hazard has two falsifiable halves: MECHANISM · REACHABILITY](feedback_hazard_mechanism_vs_reachability.md) — I verified the mechanism, never traced the earlier statements, and ACCEPTED a fence against an unreachable threat — then **embellished** it. A retraction fans out past the corrected file (tests too); a guard can outlive its rationale at a smaller size. **A shipped CAPABILITY is not a LIVE path — grep the referent of the adjective the finding hinges on.**
- [A citation has four falsifiable axes: pointer · content · extent · attachment](feedback_read_decisions_from_the_pr_branch_when_the_pr_edits_it.md) — bracketing `## ADR-` header (file is NOT in ADR-number order) · read AMENDMENTS not just the body · a verbatim quote can misstate its own scope · **an inherited citation re-hung on a NARROWER proposition supports nothing — grep the cited artifact's own words about ITSELF**; **CLAUSE-NAME BLEED: a paraphrase borrows the neighbouring sentence's mechanism names (a `CASE` cannot exclude a row — a `WHERE` does) — check the neighbours, and when comment and test disagree the test is usually right**.
- [Supplied verbatim text ships unfiltered](feedback_supplied_verbatim_text_ships_unfiltered.md) — the receiver is instructed NOT to fix my formatting, so match the TARGET FILE's convention before handing a block over; the protocol transfers the whole error budget to me.
- [temp/ hand-off paths are per-worktree](feedback_temp_handoff_path_is_per_worktree.md) — give the absolute path; a "your file is unchanged" report is a location claim, not a content claim; **commit-ready verbatim text goes in the FILE and the message — a relay may forward a pointer, not the text**.
- [Review the delivery note against the ref](feedback_review_the_delivery_note_against_the_ref.md) — a `temp/` v2 while the branch carries v1 means the green run named another tree; bound the delta (additive ⇒ FLAG, not RED). **pgTAP plan-drift = the count of CONSECUTIVE TRAILING rolled-back legs (my "always 1" was wrong); `finish()` emitting at all proves the legs RAN — the residual is numbering, settled by pg_prove's exit code.** ⚠ **A teammate's local suite figure ≠ the fenced CI lane: measure check-runs at the EXACT sha (re-poll twice), read branch protection's required contexts, and open `--json jobs` — a run whose conclusion is `failure` may be all-`cancelled`.**
- [Diff filter swallows removed comments](feedback_diff_filter_swallows_removed_comments.md) — a deleted `--` line reads as `---`; and assert "zero executable lines changed", not "comment-only", where catalog comments ship to pg_description.

- [The merge key is a tenant fence](feedback_merge_key_choice_is_a_tenant_fence.md) — joining two RLS'd reads on a global id fails CLOSED (leak → zero); joining on a label fails OPEN (labels are shared vocabulary). Comment the construction site, not the lookup.
- [Two functions, two partitions — check the axis before the arithmetic](feedback_two_functions_two_partitions_axis_mismatch.md) — an `account_type` filter and a taxonomy-`cat` filter are not interchangeable; measure `prosrc`, diff both member sets, and separate "code wrong" from "AC unsatisfiable".
- [Verify the stated correctness mechanism](feedback_verify_the_stated_correctness_mechanism.md) — "textual identity across N copies" / a declared `STABLE` is a testable claim; measure it, normalize leading whitespace, fence it WHILE it holds.
- [A label rename moves every unfenced join that branches on it](feedback_a_label_rename_moves_every_unfenced_join_that_branches_on_it.md) — "edits no function body" ≠ output invariant; find joins missing the discriminator, judge by DIRECTION, write the header note for the INVERSE case.
- [An enumeration and its watcher both stop one short](feedback_enumeration_and_watcher_stop_one_short.md) — the SIBLING DEFAULT table's FK; `polwithcheck` watched but never `polqual`; **never put a count and a `| head -N` in the same turn**; an attributed verbatim quote goes stale when its source is reworded. Never demote a control to make its prose true.
- [A shared predicate covers only that predicate — find the SECOND narrowing](feedback_shared_predicate_then_second_narrowing.md) — rendered ⊆ row set ⊆ denominator; keep BOTH arms of a two-arm binding; a watcher can be unconditional and still unarmed; check the WATCHED table is the READ table.
- [Re-derive a uniform-response rationale against the built predicate](feedback_uniform_response_rationale_vs_built_predicate.md) — an explicit `.eq('users_id')` voids every "cross-tenant existence" argument; a `USING` refusal is a 0-row effect that never reaches the error-mapper, so one verb reports success for a write the DB refused.
- [The DELETE↔SELECT policy conjunction is CONDITIONAL](feedback_rls_delete_select_policy_conjunction_is_conditional.md) — SELECT policies apply to DELETE/UPDATE only when the statement reads columns; a bare `DELETE FROM t` is gated by DELETE's `USING` alone, so that predicate is never redundant.
- [A grep over comments measures intent, not data](feedback_a_grep_over_comments_measures_intent_not_data.md) — a partition claim proved by grepping migration COMMENTS; when the rule is app-layer the ROWS can violate it. Triage violations by failure DIRECTION — the FK-less audit snapshot is the silent one.

- [A shared-namespace write has three axes](feedback_shared_namespace_write_has_three_axes.md) — overwrite · first-write squatting · **repairability**; `on conflict do nothing` clears only the first, and a "rate-limit gap" framing covers none. Measure the table's GRANTS for the repair path; no repair path ⇒ the finding blocks.

- [Backup rotation prunes its own recovery points](feedback_backup_rotation_prunes_its_own_recovery_points.md) — run the DEFENDED event through the retention policy; check dump file mode + cloud sync; never-blocking ⇒ never-watched.
