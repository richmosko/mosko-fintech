# Memory index — security-engineer

## Review method

- [Measure the fence regex, not its comment](feedback_measure_the_fence_regex_not_its_comment.md) — grep the real predicate over an evasion list; empirical probe when the matcher is someone else's engine; prescribe a positive pin over a name-denylist; **a two-stage fence leaks between the stages and NULL is the silent pass**.
- [Sec-Lock cross-check catches my own misreads](feedback_sec_lock_cross_check_catches_my_own_misreads.md) — read the source the text CITES; a relay of my OWN words is still a relay; "not in the tree" ≠ unrecoverable (Linear/DESIGN); quote an interior span.
- [Catalog comments carry live-state tallies](feedback_catalog_comments_carry_live_state_tallies.md) — a count FANS OUT (TOC + hint + body); negative-grep the old string, derive the number from a sibling catalog's convention, never sweep scoped historical deltas.
- [Zero-value sentinels flip meaning when a predicate changes](feedback_zero_value_sentinel_flips_meaning.md) — re-check EMPTY/`?? DEFAULT` **and prop defaults**; branch on the full state tuple, not one field.
- [Block when the vehicle cost inverts at merge](feedback_block_when_the_vehicle_cost_inverts.md) — return-shape rulings are free pre-merge; an assigned-but-never-read local is a dropped output column.
- [A stated invariant stronger than the contract](feedback_stated_invariant_stronger_than_the_contract.md) — "NULL together"/"exactly where" over a one-way rule; retracting a claim, quote the WHOLE sentence (the tail may be a live obligation); a forward note seeds the label it predicts.
- [Read the whole cell before diagnosing doc drift](feedback_read_the_whole_cell_before_diagnosing_doc_drift.md) — supersession looks like drift on a partial read; ask what my correction would UN-cover.
- [Corrupt-the-control canary: 5 ways it fails to bite](feedback_corrupt_the_control_canary_boundary_tie.md) — ties/loses to third-party rows on a data-bearing stack; wrong probe; framing-not-mechanism fix; two-sided leg; count-not-winner companion.
- [A RED whose message names the wrong defect](feedback_a_red_whose_message_names_the_wrong_defect.md) — the message dictates the repair, and the tempting repair (`distinct`) disables the watcher; predict the post-change delta BEFORE it runs (bind it to the PROPERTY, not the instrument); a fix that BREAKS a venue reveals what the venue was standing on; fresh-stack CI is clean by construction, not by verification.
- [Clearance conditions must absorb my own recommendations](feedback_clearance_conditions_must_absorb_my_own_recommendations.md) — "comment-only" goes stale the moment I ask for a code fix; VENUE clearances AND either/or remediations need a per-scope check (cluster vs database); ordering ≠ executability (`rolsuper` is an attribute, never inherited); probe the residual, don't hedge it.
- [My review measurements become quoted sources](feedback_my_review_measurements_become_quoted_sources.md) — a ⭐ measurement gets copied byte-exact into a later migration header; my CORRECTION carried a new typed count; a digest is a pipeline property, assert `count(distinct)=1`.
- [Read the branch from the ref, not the worktree](feedback_read_the_branch_from_the_ref_not_the_worktree.md) — a parked worktree is merges behind; `ls` makes a valid citation look fabricated.
- [A citation has three falsifiable axes: pointer · content · extent](feedback_read_decisions_from_the_pr_branch_when_the_pr_edits_it.md) — bracketing `## ADR-` header (file is NOT in ADR-number order) · read AMENDMENTS not just the body · a verbatim quote can still misstate its own scope.
- [temp/ hand-off paths are per-worktree](feedback_temp_handoff_path_is_per_worktree.md) — give the absolute path; a "your file is unchanged" report is a location claim, not a content claim.
- [Diff filter swallows removed comments](feedback_diff_filter_swallows_removed_comments.md) — a deleted `--` line reads as `---`; and assert "zero executable lines changed", not "comment-only", where catalog comments ship to pg_description.

- [Verify the stated correctness mechanism](feedback_verify_the_stated_correctness_mechanism.md) — "textual identity across N copies" / a declared `STABLE` is a testable claim; measure it, normalize leading whitespace, fence it WHILE it holds.

- [Backup rotation prunes its own recovery points](feedback_backup_rotation_prunes_its_own_recovery_points.md) — run the DEFENDED event through the retention policy; check dump file mode + cloud sync; never-blocking ⇒ never-watched.
