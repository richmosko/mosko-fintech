Money-movement fence: there is NO "Pay" / "Transfer" button. The user records a payment they made externally as a §2.4.3 manual transaction against the IRS/FTB account; YTD Paid reads from that ledger. Overpayment → Estimated Funds Due renders negative ("-$X overpaid") on the same line. Reactive due-dates only (no reminders). No-IRS/FTB-account → "create an IRS/FTB account to track payments."
