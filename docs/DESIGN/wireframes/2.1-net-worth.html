Wireframes: Shell + §2.4 · §2.1 Net Worth · §2.2 Allocation · §2.3 Cash Flow · §2.5 Taxes · §2.6 Report

Low-fi conventions + legend: see Shell page. Grayscale/structure only; Visual owns color/type/spacing later.

Decisions realized here:
  • P2 dense single-canvas, number-first — one scroll: headline+deltas → 60-mo trend → composition foot. No within-surface sub-tabs.
  • 3 distinct freshness signals (kept separate): nav-asof-timestamp (NAV materialization recency) · per-aggregation stale-data-marker (account staleness) · the incomplete-NAV "not yet computed" state (tax components from §2.5 unset).
  • Value-semantics: NAV is owned ONLY here; per-account values are gross; tax adjustment happens only at the composition foot.
  • Inflation overlay co-drawn (not a toggle); horizons/window/reference-dates fixed; NO scope filter.
